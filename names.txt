# Kagura - message ID to spoken name.
#
# The game resolves one message per menu selection change, and it is always the
# highlighted item's DESCRIPTION. The item's own label is a pre-rendered .dds
# texture inside the Scaleform .gfx, so it never passes through the text system.
# This file supplies the missing labels.
#
# Format:  <messageId> = <spoken name>
#   - An ID ending in * matches by prefix.
#   - A value of - means "never speak this".
#   - A value of ^ means "speak its own text, but FIRST in the burst".
#   - A value of + means "speak its own text normally" (used to carve an
#     exception out of a broader wildcard rule).
#   - Exact IDs win over wildcards; earlier wildcards win over later ones.
#   - Anything with no rule is still spoken, using the raw description.
#
# Reload in-game with the "names" command - no rebuild, no restart.
#
# Labels below were harvested with the "dump" command, which walks a prefix's
# numeric range through the game's own resolver. Only IDs whose description does
# NOT already state the label are mapped; self-describing text is left alone.

# ============================ button icons ============================

# ============================ suppressed ============================

# The on-screen control legend during battle and tutorials. It arrives as label /
# icon pairs and re-resolves constantly, so it is chatter during a fight. The
# deliberate "1P Command List" menu uses commandlist_* (no _demo) and is kept.
commandlist_demo_* = -

# Steam / Discord rich presence strings. Not UI text at all - they describe what
# the player is doing to *other* people.
presence_* = -

# DO NOT suppress the MSG_* button labels. They were silenced here on the
# assumption that they were only the footer legend, but they are also the
# highlighted button inside confirmation dialogs. With them muted, a Yes/No
# prompt gives no way to tell what is currently selected. Repetition is a far
# smaller problem than a dialog you cannot read. The same goes for MSG_OK,
# MSG_NextPage and MSG_PrevPage, which were suppressed here for the same wrong
# reason.

# Placeholder-only strings: these carry a value the text system never fills in
# ("<string />%"), so they reduce to punctuation and say nothing useful aloud.

# ============================ Character Select ============================
# One selection change resolves a burst: jutsu names, then the character, then the
# battle controls legend. The character is what matters, so it is pulled to the
# front.
c_cha_* = ^

# battle_* is NOT suppressed. These were silenced as a "control legend", but the
# command list proves they are the character's support abilities: Strike Back,
# Dash Cut, Charge Guard, Cover Fire, Secret Technique Substitution. That is real
# information about the selected character, so it is spoken. Burst de-duplication
# stops each one repeating, and the character's name is still announced first.
